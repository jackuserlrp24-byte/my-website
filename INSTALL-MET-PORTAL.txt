MAINTENANCE / COMING SOON
Developer panel > Panels now has a row for the whole Met Police portal and one for each tab (My Incidents, Reports, Checks, Evidence,
Statements, Roster, Policies, Communications, Command, Collisions, Firearms PIP, My Details). Pick Under maintenance or Coming soon,

For anything new you add: add a line to MAINTENANCE_PANELS in lib/maintenance-config.ts and wrap the page in PanelGate (a layout.tsx in its folder does it).

CHANGES IN THIS UPDATE
- New Roster tab (/met-police/roster): every officer with collar, rank, station, team.
- Communications: only command (and management) can post or delete notices and bulletins.
- Roster shows command only (Gold, Silver, Bronze and Met Command roles) and refreshes itself from Discord about every minute. It also copies collar numbers (from the Discord nickname) and ranks (from Discord rank roles). Edit RANKS in lib/met-discord.ts if your rank role names differ.
- New Command tab: Police Collisions (Driving Standards role or Gold Command), Firearms PIP (MO19 Command role only), plus links to announcements, officer details and LOA.
- Clicking Met Police in the Services Hub opens the portal full screen. There is also a Full screen button in the portal sidebar.
- New notification bell in the portal: unread messages plus notices and bulletins from the last 14 days.
- Duty and Training tabs removed. Delete the old folders app/met-police/duty and app/met-police/training from your project.
- My Details is now the last tab.
- The duty rota is still on the Leave of Absence page (/dashboard/command/loa), command rank only.

MDT LINK, INCIDENTS, PNC AND E-FORMS (new)
- Tabs changed: Statements removed. My Incidents -> Incidents (same list and full-incident screen as the MDT, with remarks).
  Checks -> PNC (Person / Vehicle search, record tabs, new person / vehicle). Reports -> E-Forms (the MDT forms).
  Old links (/met-police/statements, /checks, /reports) redirect to the new pages.
- Run supabase/met-portal.sql again (safe to re-run). It adds mdt_incidents, mdt_pnc_records, mdt_eforms, mdt_eform_defs.
- In Vercel add MDT_API_KEY = a long random secret, then redeploy.
- In the MDT resource (CO-MDT-with-web-link.zip): put the same secret in server.cfg
      set comdt_web_url "https://your-site.vercel.app"
      set comdt_web_key "<the MDT_API_KEY value>"
  Copy web_bridge.lua, fxmanifest.lua and server.lua over the MDT files and restart the resource.
- The MDT sends incidents, PNC and e-forms to the website every 10 seconds. PNC records made on the website are collected by the MDT.
- Old tables (met_reports, met_pnc_*, met_statements...) are left alone; nothing is deleted from the database.

COMMAND AREA (new layout)
- The Command tab opens its own area with tabs along the top: Dashboard, Submitted Forms, Announcements, LOA, then Police Collisions /
  Firearms PIP / Anti-Corruption & Abuse (each only for the roles that can open it).
- Dashboard: quick numbers (active incidents, forms waiting review, notices) and the section cards.
- Submitted Forms: every e-form, filter by form and status (command only). Announcements: post / delete notices and bulletins (command only).
- LOA: only the request form. The duty rota and the "on leave" lists are no longer shown on it.
