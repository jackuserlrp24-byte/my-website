MET POLICE OFFICER PORTAL UPDATE

1. Drag everything in this folder (app, lib, supabase, next.config.ts) into your my-website project and choose "Replace".
   The folder layout matches your project.

2. Paste supabase/met-portal.sql into the Supabase SQL editor and run it once (safe to re-run). It now also creates the Police Collisions and Firearms PIP tables.
   (If you have not already run supabase/met-announcements.sql and supabase/bodycam.sql, run those too.)

3. Role IDs (lib/training-config.ts):
     Gold   1532843318197747872   (was 1532828658979569894 in the code)
     Silver 1532828760410427432
     Bronze 1532828869944545410
   IMPORTANT: if DISCORD_GOLD_COMMAND_ROLE_ID / DISCORD_SILVER_COMMAND_ROLE_ID / DISCORD_BRONZE_COMMAND_ROLE_ID are set in
   Vercel, those override the code. Update them there too, or delete them so the code values are used.

4. NEW Vercel variable: DISCORD_MO19_COMMAND_ROLE_ID = the ID of your MO19 Command role.
   (Driving Standards uses role 1559219008744726598 by default; override with DISCORD_DRIVING_STANDARDS_ROLE_ID if needed.)
   The roster reads Discord nicknames ("[1234] Name") and rank roles, so the bot needs "Server Members Intent" switched on.

5. Redeploy.

CHANGES IN THIS UPDATE
- New Roster tab (/met-police/roster): every officer with collar, rank, station, team.
- Communications: only command (and management) can post or delete notices and bulletins.
- Roster shows command only (Gold, Silver, Bronze and Met Command roles) and refreshes itself from Discord about every minute. It also copies collar numbers (from the Discord nickname) and ranks (from Discord rank roles). Edit RANKS in lib/met-discord.ts if your rank role names differ.
- New Command tab: Police Collisions (Driving Standards role or Gold Command), Firearms PIP (MO19 Command role only), plus links to announcements, officer details and LOA.
- Clicking Met Police in the Services Hub opens the portal full screen. There is also a Full screen button in the portal sidebar.
- New notification bell in the portal: unread messages plus notices and bulletins from the last 14 days.
- Duty and Training tabs removed. Delete the old folders app/met-police/duty and app/met-police/training from your project.
- My Details is now the last tab.
- The duty rota is still on the Leave of Absence page (/dashboard/command/loa), command rank only.
